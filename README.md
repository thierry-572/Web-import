## 💎 Sobre o projeto

O **Web Import** é um projeto de desenvolvimento web que simula uma loja de importação de roupas e produtos internacionais, oferecendo uma experiência digital para clientes e uma área de acesso destinada ao proprietário.

A proposta é reunir em um único ambiente a apresentação de produtos, o cadastro de usuários e a separação dos acessos de acordo com o perfil de cada usuário.

O projeto foi desenvolvido como uma aplicação prática para explorar conceitos de criação de sites, interfaces, formulários e controle de acesso.

## ✨ Funcionalidades

- 🛍️ **Loja de produtos importados:** ambiente voltado à apresentação de roupas e outros produtos internacionais.
- 📝 **Cadastro:** interface destinada ao registro de usuários.
- 🔐 **Tela de login:** acesso por meio de usuário e senha.
- 👑 **Perfil do proprietário:** acesso destinado à administração da loja.
- 👤 **Perfil do cliente:** acesso destinado aos usuários da loja.
- 🎨 **Experiência visual:** interface desenvolvida para apresentar a proposta comercial do projeto.

> As funcionalidades disponíveis dependem da implementação atual do site.

## 👥 Perfis de acesso

O sistema foi pensado para trabalhar com dois tipos de usuário.

| Perfil | Finalidade |
|---|---|
| 👑 Proprietário | Acesso administrativo à loja |
| 🛍️ Cliente | Acesso destinado ao cliente |

### 🔑 Credenciais de demonstração

Para testar o fluxo de login durante o desenvolvimento, foram definidos os seguintes dados:

| Campo | Proprietário | Cliente |
|---|---|---|
| Login | `6767` | `1234` |
| Senha | `1234` | `4321` |

> ⚠️ **Importante:** essas credenciais devem ser utilizadas somente em ambiente de demonstração. Não utilize senhas reais ou administrativas em um repositório público. Se o login estiver implementado apenas no JavaScript do navegador, os dados poderão ser descobertos por qualquer pessoa que inspecione o código. Uma aplicação real precisa de autenticação e autorização no servidor.

## 🚀 Como executar

1. Acesse o repositório do projeto.
2. Clique em **Code** e escolha **Download ZIP**, ou clone o repositório.
3. Extraia os arquivos, caso tenha baixado o ZIP.
4. Abra o arquivo principal HTML no navegador.

### Clonar o repositório

```bash
git clone https://github.com/thierry-572/Web-import.git
```

Entre na pasta:

```bash
cd Web-import
```

Abra o arquivo `index.html` no navegador, caso esse seja o arquivo principal do projeto.

> Se o projeto utilizar um servidor, dependências ou outra estrutura de execução, siga as instruções correspondentes à sua implementação.
